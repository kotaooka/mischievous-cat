# 🐈 こっそりネコ（Mischievous Cat）

**日本語** | [English](README.en.md)

**飼い主の目を盗んで、家じゅうのものを落とせ。**
コップも、花瓶も、スマホも。あなたはただの「かわいいネコ」です。……たぶん。

### ▶ [いますぐ遊ぶ](https://kotaooka.github.io/mischievous-cat/)

![こっそりネコ](og.png)

- ブラウザで開くだけ。インストール・登録は要りません（スマホでも PC でも）
- ホーム画面に追加すると、アプリのように起動できます。一度開けばオフラインでも遊べます。新しい版が出ると、タイトル画面に「タップで更新」が出ます
- 7 日間のいたずらの腕前を、みんなのランキングで競えます
- 英語にも対応しています。端末の言語が日本語以外なら英語で始まり、タイトル画面とポーズ画面でいつでも切り替えられます

## 🐾 30 秒でわかる遊び方

1. **ものの横まで歩いて、パンチ！** テーブルや棚のものを床へ落とすと「被害額」がたまります
2. **飼い主に見られたらアウト。** 「？」が出たら要注意、「!!」は監視中。家具から降りて、ふつうのネコのふりをしましょう
3. **部屋のものを全部落とせばクリア。** 朝・昼・夕方の 3 部屋と「とくべつな夜」で 1 日。まずは **3 日目の夜**を目指しましょう。……その先のことは、越えてからのお楽しみ

途中でやめても大丈夫です。面が始まるたびに自動でセーブされ、次に開いたときタイトルの「つづきから」でその面から再開できます（見つかって終わったときは、その日の朝から。1日目なら、その面から）。「つづきから」にはその日の残りの面数も出ます。

床を歩く、ジャンプする、鳴く、ごはんを食べる。これは「ネコとしてふつう」なので、見られても怒られません。怒られるのは**いたずらの現場を見られたときだけ**です。

## 🎮 操作

| やること | スマホ | PC |
|---|---|---|
| 歩く | 画面下の ＜ ＞ | ← → / A D |
| ジャンプ | ジャンプ | Space / ↑ / W |
| パンチ（長押しで必殺ネコパンチ） | パンチ | 左クリック / Z |
| 鳴く（長押しで長く、3回連打で「にゃにゃにゃ!」） | にゃー | 右クリック / X |
| ひとやすみ | 右上の ⏸ | Esc / P |

PC では、タイトル画面の「あそぶ」と結果画面の「もう一回」は Enter（ゲームパッドは A）でも押せます。ポーズから戻るときは 3・2・1 を数えてから動き出します。

PC はゲームパッドでも遊べます（十字キー／左スティックで移動、A ジャンプ、X か B パンチ、Y 鳴く、START ポーズ）。音量・振動・ボタンの左右反転・演出（画面の揺れ・ズーム・点滅をひかえめにする）は、タイトル画面の「**設定**」で変えられます。

下のボタンを使わずに遊びたいときは、「**設定**」で「スティック操作」を ON に。ゲーム画面の**どこでも指を置いた所がスティック**になります。左右にずらして歩き、上にはじいてジャンプ、短くタップでパンチ（タップした側を向きます）、動かさずに長押しで必殺ネコパンチ・爪とぎ、ネコをタップで鳴きます。

## 💡 うまくなるコツ

- **見回りの合間がチャンス。**「ドタドタ」という足音は、飼い主が戻ってくる合図です
- **「にゃー」で気をそらす。** 飼い主はネコが向いている側を見ます。その隙に反対側でいたずら
- **飼い主の「ながら」を狙う。** 電話・料理・読書・歯みがきに夢中な間は、見える範囲がぐっとせまくなります
- **カメラ目線で落とすと「確信犯」。** ものの横でじっとしていると、ネコがこっちを見つめます。そのままパンチ！
- **ばれずに落とし続けると「こっそり」ボーナス。** 落とすたびに上乗せが大きくなります
- **点を伸ばすのは腕前。** 落とすものの値段は面ごとにほぼ決まっています。差がつくのは、連鎖・こっそり・確信犯・技（毛糸玉やニワトリで落とす）の上乗せと、面クリアの手際（残り時間）・完全犯罪（怪しまれ度 30% 未満）のボーナスです
- **見つかっても、あきらめない。** 1面に2回まで、3秒以内に隠れ場所（ダンボール・キャットタワー・本棚・カーテンレールの上）へ逃げ込めばセーフ
- **キラキラ、矢印、爪あとのマーク**が出たら、そこに何かがあります。言葉の説明はありません。触って確かめてみてください

### 3 日目の夜を越えたら

ここから先は書きません。ヒントだけ置いておきます。

- **エンディングは 1 つではありません。** どんなネコだったか――こっそり派か、大暴れ派か――を、飼い主はちゃんと見ています
- **飼い主の日記をよく読んで。** 毎晩 1 行ずつ増えていきます。部屋の様子も、少しずつ変わっていきます
- **まだ行っていない部屋があります。** 家の外にも
- **この家にいるのは、飼い主とネコだけではないかもしれません。** 床を走るもの、空から来るもの……
- **7 日目の夜**を越えたとき、何が待っているかは自分の目で

数字やルールの全部を知りたい人は [くわしいルール](docs/rules.md) へ（**ネタバレを含みます**）。

ジャンプが少し届かなくても、段の端をつかんでよじ登れます（その間は飼い主に見えます）。

### ちょっとしたネタ

家のあちこちに、小さなネタを仕込んであります。ネコの種類や見つかり方、日付によっても……。いろいろ試してみてください。

画面の右上には、落とすべきものが絵と個数（×2 など）で縦に並びます。家具は部屋ごとに違い（リビングのソファー、キッチンの食器棚と電子レンジ、書斎のデスクチェア、寝室の鏡台と宮付きベッド、子ども部屋の二段ベッドなど）、乗れる場所の並びも部屋ごとに違います。壁の棚・吊り棚・エアコンの位置は面ごとに変わります。

## 🏆 ランキングといたずら図鑑

- **みんなのランキング（総合）**：1 回のプレイの被害額で競います。7 日目の夜を越えれば完走で、完走した人どうしは腕前のボーナスで差がつきます。結果画面でニックネームを登録すると、遊んだ人全員の上位 50 人に載ります（1 端末 1 件）。記録を送るのは自己ベストを更新したときだけで、名前を変えたときも、次に自己ベストを更新したときから新しい名前で載ります
- **今日のランキング**：その日（日本時間）だけの順位です。同じ日なら、だれが遊んでも面ごとのものの置き場所・足場の配置・天気が同じになります。記録は「総合」と「今日」の両方に、それぞれ自己ベストを更新したときに送ります
- **LINE で送る**：結果画面の「LINE で送る」は、文章とリンクを送ります（「シェア」は画像つき。LINE では画像だけになります）。PC の「シェア」は画像をコピーしてから X の投稿画面を開くので、投稿欄に貼り付けてください
- **記録**：タイトル画面の「記録」で、ランキング・いたずら図鑑・通算記録をタブで切り替えて見られます
- **通算記録**：タイトル画面の「記録」の「通算」タブで、通算の被害額やよく割ったもの、退治したネズミの数などを見られます
- **この端末のランキング**：自分の上位 10 件
- **大技**：部屋ごとに 1 つ、家具を丸ごと崩す仕掛けがあります（本棚なだれ、冷蔵庫なだれ…）。上のものが全部落ち、飼い主はしばらく固まります。条件はいたずら図鑑のカードで確かめられます
- **いたずら図鑑**：72 枚のカード（1 回のプレイで取るものと、通算で取るもの）を、初めて成功した瞬間の写真つきで集めます。「記録」の「いたずら図鑑」タブで、まだのカードの取り方も見られます。決まったカードを取ると**きせかえ**が手に入ります
- **きせかえ**：決まったカードで手に入ります（「にゃー作戦」で鈴の首輪、「ボス猫撃退」でバンダナ、など。ロックの札にカード名が出ます）。それぞれ小さな効き目があり（パンチ +15%、ジャンプ +10% など）、タイトルの「ネコとおしゃれ」でネコを選び、きせかえは絵のボタンでつけ替えます（目盛りと効き目の一言が変わります。手に入れ方は、ロック中は押すと、手に入れたあとは効き目の下に出ます）
- **トイカメラ**：結果画面で「シェア」か「LINEで送る」を押すと、きせかえ「トイカメラ」が手に入ります。つけているとシェア画像が手配書（WANTED）になります
- **称号**：結果画面の称号は 1 回の被害額で決まります（見習いネコ〜伝説の食器破壊者の 5 段階）
- **犯行現場写真**：見つかった瞬間のネコのまわりが、ポラロイド写真になります（お題や数字は写りません）。何のゲームかの一文と遊べる場所も入ります。結果画面の写真をタップすると大きく見られます。SNS でシェアしてください（`#こっそりネコ`）
- **不正な記録**：署名のない記録や、ありえない被害額の記録は、ランキングに載りません

## ❓ よくある質問

- **お金はかかる？** かかりません。広告もありません
- **音が出ない** 右上のスピーカーのボタンを確認してください。iPhone はマナーモードだと鳴らないことがあります
- **振動しない（Android）** 端末の設定 → 音設定 → バイブレーションとハプティクス → **「タッチ操作時のバイブレーション」** が 0 だと、ブラウザからの振動は鳴りません。少し上げてください（Xperia / Chrome で確認）
- **新しくしたのに古いまま** 一度閉じて開き直してください（オフライン用に前の版が残っていることがあります）
- **データは？** 記録は端末の中に保存します。みんなのランキングに登録したときだけ、ニックネームと記録を送ります
