# こっそりネコ（mischievous-cat）

飼い主に見つからないように、家中でいたずらをして「本日の被害額」を稼ぐ縦画面の Web ゲームです。

**https://kotaooka.github.io/mischievous-cat/**

[QC Workbench](https://kotaooka.github.io/) の「コーヒーブレイク」に載せています。スマホの親指操作を前提にしていて、PC でも遊べます。

## 遊び方

- ネコを動かして、部屋のものを前足で押して床や下の段へ落とします。ステージのものを全部落とすとクリアです。落とすたびに、そのものの値段が被害額に入ります。
- 飼い主は部屋を巡回します。「？」は予告、「!!」は監視中です。見られている間に動く、前足を出す、ものが動いている、と怪しまれ度が上がり、100% で見つかってゲームオーバーです。止まっていれば上がりません。
- 飼い主はテーブルを確認する、棚を見上げる、スマホを見るのいずれかで止まります。スマホの間は視野が狭く、ときどき「！」の合図のあとに顔を上げます。
- 怪しまれ度が高いと「なんかおかしいな？」と探索を始めます。探索中は下がりません。
- ステージが進むと、ものが増え（最大 8 個）、飼い主の離席と予告が短く、監視が長くなります。1 回のプレイは 3〜5 分ほどです。

### 足場

床、サイドテーブル、テーブル、キャットタワー、壁の棚、本棚の順に高くなります。ジャンプで登れ、降りるときは端から落ちます。テーブルから棚、棚から本棚の順に登ります。メインクーンはジャンプが低いですが、どの足場にも登れます。

### パンチと「鳴く」

- パンチはタップで弱、長押し（約 0.35 秒）で強です。強パンチは遠くまで届き、重いものも飛ばせますが、音が出て怪しまれます。
- 「鳴く」と、飼い主はネコが向いている側を見ます。その隙に反対側でいたずらします。探索中と離席中は効きません。

### 水たまり、障害物

- 水たまりの上ではネコが滑ります。ぬれた足で歩くと足跡が残り、飼い主が見ると怪しまれます。
- ダンボールの中（床）とキャットタワーの上は、飼い主から見えません。
- お掃除ロボ（ステージ 3 から）に当たると、動けなくなって怪しまれます。ジャンプで避けられます。
- 犬（ステージ 4 から）は寝ています。近くで動いたり、近くで大きな音を出したりすると吠え、飼い主が駆けつけます。

### 結果とシェア

ゲームオーバーで「本日の被害額」、ステージ、称号、飼い主のコメントを表示し、シェア用の画像（1200×630）を作ります。「シェア」は端末の共有画面（Web Share API）を開き、使えない環境では X の投稿画面を開きます。「画像を保存」で PNG を保存できます。ハッシュタグは `#MischievousCat` と `#こっそりネコ` です。

称号は、1 プレイの被害額で決まります。

| 被害額 | 称号 |

| ¥200,000 未満 | キッチンの悪夢 |
| ¥500,000 未満 | リビング崩壊請負猫 |
| ¥500,000 以上 | 伝説の食器破壊者 |

## 操作

| 操作 | PC | スマホ |
|---|---|---|
| 左右に移動 | ← → / A D | 画面下の ◀ ▶ |
| ジャンプ | ↑ / W | ジャンプ |
| パンチ（長押しで強パンチ） | Space / Z | パンチ |
| 鳴く | X | 鳴く |
| 音の ON / OFF | M | なし |

## データについて

ブラウザの中だけで動きます。保存するのはベストの被害額と選んだネコだけで、端末の外へは送りません。シェア画像はブラウザの中で作ります。「シェア」や「Xに投稿」を押したときだけ、共有先へ文面（と画像）を渡します。画面の字体は Google Fonts から読み込むため、開いたときに Google のサーバーへ接続します。スコアなどのデータは送りません。
