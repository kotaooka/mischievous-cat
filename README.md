# こっそりネコ（mischievous-cat）

ネコを操作して、飼い主に見つからないようにテーブルのコップを全部落とす Web ゲームです。

**https://kotaooka.github.io/mischievous-cat/**

[QC Workbench](https://kotaooka.github.io/) の「コーヒーブレイク」に載せています。

## 遊び方

- ネコを左右に動かし、前足でコップを押してテーブルの外へ落とします。コップを全部落とすとステージクリアです。
- 飼い主は「離席 → ？（予告）→ !!（監視中）」を繰り返します。「!!」の間にネコが動く、前足を出す、コップが動いている（落下中を含む）と、怪しまれ度が上がります。100% になると見つかってゲームオーバーです。
- 「？」の間も、動くと少しずつ怪しまれ度が上がります。離席中にコップが割れると、怪しまれ度が上がり、飼い主が早く戻ってきます。
- ステージが進むと、コップが増え（最大 5 個）、飼い主の離席時間と予告の時間が短くなります。
- スコアは、コップ 1 個につき 100 点です。クリアすると、300 点とタイムボーナスが入ります。ベストスコアはブラウザ（localStorage）に保存します。

| 操作 | PC | スマホ |
|---|---|---|
| 左右に移動 | ← → / A D | 画面下の ◀ ▶ |
| 前足で押す | Space / Z | 画面下の「落とす」 |
| 音の ON / OFF | M | なし |

## データについて

ブラウザの中だけで動きます。保存するのはベストスコアだけで、端末の外へは送りません。画面の字体は Google Fonts から読み込むため、開いたときに Google のサーバーへ接続します。スコアなどのデータは送りません。
